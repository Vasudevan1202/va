Project Overview & Educational Purpose

STEM • IoT Science

Virtual Atmosphere (VA) is a school environmental monitoring and Internet-of-Things (IoT) science platform designed to cultivate hands-on understanding of physical atmospheric phenomena, embedded Linux systems, and real-time telemetry.

By connecting a precision Bosch BMP280 environmental sensor directly to a Raspberry Pi 3 Model B+ via the hardware Inter-Integrated Circuit (I²C) bus, the platform continuously measures, validates, logs, and visualizes local ambient temperature and barometric pressure.

Direct I²C
Direct hardware connection, zero intermediate microcontrollers (No ESP32)
Local SQLite
Zero cloud dependencies; fully offline school intranet deployable
Active Warnings
Configurable threshold detection with persistent audit logging

Scientific Atmospheric Principles

Atmospheric pressure reflects the weight of the air column pressing down on the Earth's surface. At sea level, standard atmospheric pressure is 1013.25 hPa (hectopascals). Weather systems induce barometric fluctuations: rising pressure typically correlates with denser, cooler, or clearing air, whereas falling barometric trends often indicate advancing storm fronts or low-pressure troughs.

The BMP280 sensor also records subtle semi-diurnal atmospheric tides—a worldwide cyclic pressure wave with peaks around 10:00 and 22:00 local solar time, caused by solar heating and absorption in the upper atmosphere.

Hardware Specifications

Verified Setup
  • Host Computer:
    Raspberry Pi 3 Model B+ (Quad Core 1.4GHz, 1GB RAM)
  • Sensor Module:
    GY-BMP280 Barometric Pressure & Temperature Breakout
  • Hardware Interface:
    I²C Bus 1 (/dev/i2c-1), 3.3V Logic Level
  • Operating System:
    Raspberry Pi OS (Debian Bookworm / Bullseye 32 or 64-bit)
  • Operating Voltage:
    3.3V DC (Physical Pin 1)
Humidity Transparency Notice

The BMP280 silicon chip contains piezoresistive pressure and temperature cells. It does not contain a relative humidity sensor (unlike the BME280). Virtual Atmosphere adheres to honest scientific reporting and never synthesizes or displays fake humidity data.

System Architecture & Data Pipeline

Layer 1: Sensor
Bosch BMP280
Direct I²C bus polling, hardware registers, calibration polynomial
Layer 2: Engine
SensorService
Python daemon thread, range validation (-40 to 85°C), alert triggers
Layer 3: Storage
SQLite (WAL Mode)
Zero-overhead, persistent ACID storage, parameterized indexing
Layer 4: Interface
Flask & Chart.js
REST API + Dark Theme responsive telemetry interface
